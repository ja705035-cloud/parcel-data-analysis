# Parcel Data Analysis

A Python-based parcel data analysis and management project developed as part of my T Level Digital Software Development course.

## About the Project

This project involves working with parcel data stored in CSV files and using Python to process, analyse and present the information.

The project was designed around a parcel management/CRM scenario, where data needs to be organised and analysed to help understand parcel information and business activity.

## Features

- Importing parcel data from CSV files
- Processing and manipulating data using Python
- Using pandas to analyse datasets
- Filtering and searching parcel information
- Calculating useful statistics
- Creating charts and visualisations using matplotlib
